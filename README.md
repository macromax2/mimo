# Seller Analytics - Реальный WB API

Сервис аналитики для продавцов Wildberries с реальным API.

Демо на GitHub Pages: https://macromax2.github.io/mimo/

Важно: GitHub Pages запускает только статический frontend, поэтому там работает демо-режим. Для подключения WB API-токена нужен запущенный Python backend.

## Быстрый старт

### 1. Получите API токен

1. Зайдите в личный кабинет продавца WB
2. Перейдите в **Настройки → Доступ к API**
3. Создайте новый токен с правами:
   - Статистика (заказы, продажи)
   - Контент (товары)
   - Аналитика (остатки)
4. Скопируйте токен

### 2. Настройте окружение

```bash
cp .env.example .env
# Отредактируйте .env и вставьте токен
```

### 3. Запустите сервер

```bash
python3 -m src.main
```

### 4. Откройте в браузере

http://127.0.0.1:8090/app

## Деплой backend

На Render/Railway/Fly.io используйте:

```bash
pip install -r requirements.txt
python3 -m src.main
```

Переменные окружения:

| Переменная | Значение |
|------------|----------|
| `HOST` | `0.0.0.0` |
| `PORT` | порт платформы, обычно задается автоматически |
| `API_MODE` | `real` по умолчанию |

## Режимы работы

| Режим | Описание |
|-------|----------|
| `mock` | Тестовые данные (по умолчанию) |
| `real` | Реальный WB API |

## Доступные эндпоинты

| Эндпоинт | Описание |
|----------|----------|
| `/api/dashboard` | Главная панель |
| `/api/products` | Список товаров |
| `/api/analytics/pnl` | P&L аналитика |
| `/api/analytics/stocks` | Остатки |

## Лимиты API

- Orders/Sales: 1 запрос в минуту
- Stocks: 1 запрос в минуту
- Finance: 1 запрос в минуту
- Products: 1 запрос в 6 секунд
